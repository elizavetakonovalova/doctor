# Кабинет

Базовый каркас личного приложения для учёбы в медицинском вузе: база знаний, карточки, тесты и билеты.

Сейчас это только оболочка. Учебных материалов внутри нет — разделы показывают, куда позже лягут записи, карточки и вопросы.

Открывается как обычная страница: `index.html`, без сборки. Данные задуманы как локальные (в браузере), отдельного сервера нет.

## Разделы

- **Обзор** — вход и четыре будущих раздела
- **База знаний** — конспекты и темы
- **Карточки** — самопроверка лицом и оборотом
- **Тесты** — вопросы с вариантами ответа
- **Билеты** — подготовка к экзаменационным билетам
